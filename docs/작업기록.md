## 환경 메모

- **Vercel CLI 한글 PC 이름 문제**: `Cannot convert argument to a ByteString` 오류. `os.hostname()`·`os.userInfo().username`을 영문으로 덮어쓰는 preload 스크립트를 `NODE_OPTIONS="--require hostfix.cjs"`로 주입해 해결(README 참고).
- Vercel 배포별 고유 URL(`*-1860.vercel.app`)은 Vercel 로그인 보호가 걸려 외부에서 열리지 않음. 검증은 프로덕션 별칭으로.
- 내장 브라우저에서 `html { scroll-behavior: smooth }` 때문에 `scrollTo` 직후에는 스크롤 이벤트가 바로 안 잡힘 → 검증 스크립트에서 `scrollBehavior='auto'`로 바꿔 실행.
